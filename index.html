What actually happens when you contribute

Open source sounds intimidating until you have done it once. It is really just five steps, and every project on GitHub works the same way.

  1. Fork

    You make your own copy of someone else's project. You cannot break anything — the original is untouched.

  2. Branch

    Inside your copy you create a branch: a separate line of work, so your change is kept apart from everything else.

  3. Change

    You edit a file. It can be one line. The size of the change is not what makes it a contribution.

  4. Push

    You send your branch back up to GitHub.

  5. Pull request

    You ask the maintainers to pull your change into the original project. They read it, maybe suggest something, and merge it.

That is genuinely all of it

Everything else — CI, code review, merge conflicts — is detail layered on top of those five steps. Learn these and you can contribute to almost any project on GitHub.
